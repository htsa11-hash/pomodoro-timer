# Cabo（カボ） - カードゲーム Web アプリ

スペイントランプ40枚を使ったカードゲーム「Cabo」を、1台の端末を回して遊ぶ
**ローカルマルチプレイ**として実装した React + TypeScript 製の Web アプリです。

## 起動方法

```bash
cd cabo-game
npm install
npm run dev
```

コマンド実行後に表示される URL（例: `http://localhost:5173/`）をブラウザで開いてください。
スマホでも遊べるようにレイアウトを作っているので、同じネットワーク内のスマホから
`npm run dev -- --host` で起動した URL にアクセスして遊ぶこともできます。

その他のコマンド:

```bash
npm run build    # 本番用ビルド (dist/ に出力)
npm run preview  # ビルド成果物をローカルで確認
npm run lint     # ESLint によるチェック
```

## 遊び方

### 使用カード

スペイントランプ40枚（オロス・コパス・エスパダス・バストスの4スート × 1, 2, 3, 4,
5, 6, 7, 10(ソタ), 11(カバロ), 12(レイ) の10ランク）を使用します。
カードの点数 = ランクの数字で、**手札4枚の合計点が一番低い人が勝ち**です。

### 基本ルール

1. ゲーム開始時、各プレイヤーに裏向きで4枚のカードが配られます。
2. 最初に自分の手札のうち2枚だけを確認できます（その後は基本的に見られません）。
3. 残りのカードは山札になり、山札の一番上をめくって捨て札を作ります。
4. 自分の番では
   - 山札からカードを1枚引き、
   - そのカードを「自分の手札と交換する」か「そのまま捨てる」かを選びます。
   - 交換した場合、元の手札は捨て札の上に置かれます。
5. **捨てたカードが 10 / 11 / 12 の場合、特殊効果を使うことができます**
   （※効果はそのカードを「捨てたとき」だけ発動します）。
   - `10`（ソタ）：自分のカードを1枚見る
   - `11`（カバロ）：相手のカードを1枚見る
   - `12`（レイ）：自分のカードと相手のカードを1枚ずつ、中身を見ずに交換する

### 捨て札と同じ数字に挑戦（バーン）

捨て札の一番上と同じ数字のカードを自分（または他の誰か）が持っていると思ったら、
「捨て札と同じ数字に挑戦する」ボタンからいつでも挑戦できます。

- 当たれば、そのカードを公開して捨てることができ、手札が1枚減ります。
- 外れた場合は、ペナルティとして山札からカードを1枚引いて手札に加えます。

### Cabo 宣言

自分の番が来たとき、山札を引く前に「Cabo 宣言」ができます。

- 宣言すると、他の全プレイヤーが1回ずつ行動した時点でラウンドが終了します。
- ラウンド終了後、全員の手札を公開して合計点を計算し、**最も合計点が低いプレイヤーの勝ち**です。

### 画面を見られないようにする工夫（ローカルマルチプレイ）

1台の端末を回して遊ぶため、自分の手札やめくったカードなど「自分だけが見てよい情報」は
専用のオーバーレイ画面（カードを確認する直前に「画面を他のプレイヤーに見られないように
してください」という案内が出る画面）でのみ表示されます。確認が終わったら、画面を次の
プレイヤーに渡してください。

## プロジェクト構成

```
src/
  game/
    types.ts        # ゲームの型定義（カード・状態・アクション）
    deck.ts         # デッキ生成・シャッフル・山札からカードを引く処理
    interaction.ts  # 「今どのカードがタップ可能か」を判定するヘルパー
    reducer.ts      # ゲームのコアロジック（useReducer 用 reducer）
  components/
    App.tsx              # アプリのエントリーポイント（セットアップ画面 / ゲーム画面の切り替え）
    SetupScreen.tsx      # 人数・名前を入力してゲームを開始する画面
    GameBoard.tsx        # 山札・捨て札・各プレイヤーの手札・操作パネルをまとめる盤面
    PlayerArea.tsx       # 各プレイヤーの手札表示
    Card.tsx             # 1枚のカードの表示（裏向き / 表向き）
    Controls.tsx         # 「引く」「そのまま捨てる」「Cabo宣言」などの操作ボタン
    ScoreResult.tsx      # ラウンド終了時の結果発表（手札公開・順位・合計点）
    RevealOverlay.tsx    # カードを確認するためのオーバーレイ（画面を隠す案内つき）
    MatchAttemptModal.tsx# 「捨て札と同じ数字に挑戦」のプレイヤー・カード選択モーダル
```

## 技術スタック

- React + TypeScript（Vite）
- 状態管理: `useReducer`（`src/game/reducer.ts` にゲームロジックを集約）
- スタイリング: シンプルな CSS（コンポーネントごとに `.css` ファイルを分割）
