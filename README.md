# 🍅 ポモドーロ・タイマー

シンプルなブラウザ用ポモドーロタイマーです。作業・小休憩・長休憩のタイマーに加えて、タスク管理機能を備えています。

## 機能

- 作業 (25分) / 小休憩 (5分) / 長休憩 (15分) の3モード切り替え
- タイマーの開始・一時停止・リセット
- タイマー終了時にアラーム音を再生
- 完了したポモドーロ数のカウント(`localStorage` に保存)
- タスクの追加・完了・削除(`localStorage` に保存)

## 使い方

`index.html` をブラウザで開くだけで利用できます。サーバー設定やビルドは不要です。

```
start index.html
```

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の構成(マークアップ) |
| `style.css` | 見た目のスタイル |
| `script.js` | タイマーとタスク管理のロジック |
